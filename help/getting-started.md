# Your first measurements

## Connect Caldwell

1. Open **Sources**, choose **Caldwell**, and give the source a name.
2. Select **Add source**, then enter your Caldwell email and password.
3. Choose **Sign in and import**. When it finishes, select a string on the left.

You only need account credentials. Connection setup happens automatically. VelociTrack reads your own measurements and does not change your Caldwell account data.

Want to stay signed in? Enable **Allow sign-in to be remembered on this device** in [your profile](profile.md). Use the same browser and address next time.

## Import files instead

1. Add a source of type **JSON / text**.
2. Select your combined JSON file, or the matching strings and shots files together.
3. Open a string to explore its chart and table.

JSON, CSV, and text exports are supported. Files stay on your device. Preparing an export yourself? Use the separate [file format reference](../docs/IMPORT_FORMAT.md).

## Bring in new measurements

Use **Refresh** to update all enabled sources, even ones hidden by filters. Connected sources use their available sign-in; file sources ask for the latest files. **Continue in background** lets you work during an import.

Repeat imports update matching records without duplicates. **No new data detected** means no new strings or shots were added; existing records may still have changed. Local notes, invalid-shot marks, tags, and photos are preserved.

## Find the right string

Use Source, Firearms, Projectiles, Tags, or date filters. Several items inside one filter match any of them; combining filters narrows the result. Choices save automatically.

Select several strings to compare them. A string hidden by a filter leaves the active chart.
