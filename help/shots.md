# Keep the shots you want

## Choose what enters analysis

Uncheck **Analyze** on a row to leave it out of charts and statistics. The row stays available so you can include it again.

The checkbox beside the **Analyze** heading selects or clears every eligible row in the current table, including other pages. A mixed checkbox means only some rows are selected. It skips locally invalid shots.

Ordinary Analyze choices last until reload. A source-excluded shot can still be inspected, but never contributes to charts or statistics.

## Mark a shot invalid

Select the **red ×** at the far right. Analyze turns off, the row dims to suit your theme, and the action becomes **Undo**.

The mark is saved across reloads, imports, and workspace backups. The original measurement remains available for recovery. Select the **Undo arrow** to restore the row and include it again. A source exclusion still applies if Caldwell supplied one.

> [!TIP]
> Use Analyze for a temporary comparison. Use the red × for a bad reading you want to keep excluded next time.

## Sort and arrange

Table headings use compact names such as **V₀** (muzzle velocity), **G1/G7**,
**Offset H/V**, **Group size** and **String SD/ES**. Units appear below the name.
Hover, focus or tap a heading to read its full meaning, scope and source; press
Escape or tap elsewhere to close the explanation. The arrow beside it sorts.
Your custom field names remain unchanged. Columns retains full names for lookup.

- Select the arrow beside a column name to sort ascending, then descending. Missing values stay last.
- The default is **String**, then Shot number. Shot alone has no sort button.
- Open **Columns** to choose values. Checking or unchecking a column keeps its position in the list and table. Re-enabling it restores that position.
- Drag any column, including a hidden one, by its grip; a floating card and **Insert here** marker show the result. Up/Down buttons also work with the keyboard. Only these moves change the order.

Sorting, column selection, and column order are saved and backed up. Simple/Dual By shot follow table order. String compare keeps that relative order within each string. Distance charts keep physical distance coordinates.

## Link a row to its chart

Point at a row or focus it with the keyboard to highlight its plotted values. Point at a chart value to reveal matching rows. A mean can represent several shots; all contributors are highlighted.

Tables show 100 rows per page. Following a chart point can reveal a later page automatically.
