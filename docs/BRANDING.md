# Brand assets

The owner supplied the VelociTrack web icon package on 2026-10-18. Original assets live in `public/brand/` and are served at the application's base path. The ZIP itself is not part of the repository.

- `favicon.svg`: scalable header mark and modern browser favicon.
- `favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png`: browser/desktop icon variants.
- `apple-touch-icon.png`: 180 px Apple touch icon.
- `android-chrome-192x192.png`, `android-chrome-512x512.png`: installable application icons.

The header uses a 44 px square mark on desktop and 36 px on narrow screens. The product name remains text so it stays readable. Preserve aspect ratios and use an empty alt attribute beside the visible product name to avoid duplicate announcements.

The supplied PNG icons are declared with `purpose: any`; their artwork has not been prepared or verified for maskable cropping. Do not relabel them as maskable without suitable safe-area artwork.
