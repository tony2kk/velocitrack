# 010 — Persistent shot invalidation, model velocity and task-based help

Accepted with the owner on 2026-10-19, extending decisions 004, 008 and 009.

- The row's fixed rightmost red cross marks a shot locally invalid. This is a persistent reversible exclusion, matching the requested Undo workflow; imported data are retained. Annotation.invalid belongs to the shot identity and cannot be overwritten by a source refresh. Invalid rows are dimmed, Analyze is disabled/unchecked, and Undo restores normal selection. Provider exclusion remains authoritative. Backup includes the annotation; removing the source cleans it transactionally. No provider writes or hard shot deletion are introduced.
- Analyze has a tri-state heading checkbox that operates across all rows/pages of the current selected-string table, skipping locally invalid shots. Ordinary Analyze exceptions remain page-memory choices; bulk changes preserve exceptions outside that table.
- Over distance offers Calculated velocity (G1)/(G7) when the shot's recorded muzzle speed and matching BC support the reference model. Simple/Dual/Compare support these choices, with Dual comparing recorded and calculated curves on the same velocity scale. The prediction horizon is persisted independently for each analysis, in canonical feet. Dashed curves/tooltips and a visible assumptions notice distinguish estimates from measurements. Model work is bounded and contributor linkage is retained.
- Use the explicitly stated standard-atmosphere, constant-BC, straight-path drag-only model in [VELOCITY_RESEARCH.md](../VELOCITY_RESEARCH.md). Do not silently interpret unvalidated weather units, replace observations, or claim increased accuracy. The owner agreed to omit independently recalculated G1/G7 attributes. Original Caldwell coefficients remain available.
- Help remains linked from the header to help/README.md, now a concise hub with task-oriented linked pages. Technical file contracts and numerical research are separate developer references. No new website hosting or runtime documentation dependency is needed.

Additive optional annotation/chart properties require no IndexedDB schema migration and validate through the existing ZIP contract. The public data table attribution is included with static assets. No private records, SDK sessions or credentials are committed. The standing verified commit/push workflow applies; Pages deployment remains separate.
